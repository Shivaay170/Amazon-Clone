# 🛒 Amazon Home Page Clone

A responsive **Amazon Home Page Clone** built to practice and improve frontend web development skills.

## 🚀 Features

* Amazon-inspired navigation bar
* Search bar and category navigation
* Hero/banner section
* Product/category cards
* Responsive layout
* Amazon-style footer

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
